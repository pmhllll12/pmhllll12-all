# 자동 메모리 동작 방식

## 로드 규칙

- `MEMORY.md`의 **첫 200줄**이 매 세션 시작 시 시스템 프롬프트에 자동 로드된다.
- 200줄을 초과하는 내용은 자동 로드되지 않는다 (Claude가 필요할 때 읽는다).
- 상세 내용은 `debugging.md`, `patterns.md` 같은 **별도 주제 파일**로 분리한다.
- 주제 파일은 필요할 때만 읽힌다 (시작 시 전부 로드하지 않는다).
- **200줄 제한은 `MEMORY.md`에만** 적용된다.

### CLAUDE.md와의 차이

- 200줄 제한은 **자동 메모리 전용** 설정이다.
- `CLAUDE.md`는 길이에 관계없이 전체가 로드된다. 다만 200줄 이내로 유지하는 편이 지시사항 준수율을 높이는 데 도움이 된다.

## 활성화 / 비활성화

자동 메모리는 **기본적으로 활성화**돼 있다. 비활성화하려면 아래 중 하나.

### 방법 1 — 환경변수

    export CLAUDE_CODE_DISABLE_AUTO_MEMORY=1

### 방법 2 — settings.json

    {
      "autoMemoryEnabled": false
    }

다시 활성화하려면 환경변수를 제거하거나 `autoMemoryEnabled`를 `true`로 설정한다.
